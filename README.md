# 오렌지3 지진 데이터 탐구

고등학교 1학년 데이터 과학 수업용 실습 웹앱입니다. 학생들은 오렌지3(Orange Data Mining)로 최근 약 10년간의 국내 지진 데이터를 직접 분석하면서 단계별 문제를 풉니다. 이 웹앱은 기존 PDF 학습지를 바꾼 것입니다.

- **주소:** https://onezerozerocom.github.io/orange3-earthquake/

## 이렇게 진행됩니다

학생은 각 미션에서 **오렌지에서 따라 하기** 단계를 보며 직접 실습합니다. 그다음 오렌지 화면에서 읽은 값으로 **문제**를 풉니다.

- **따라 하기:** 짧은 지시와 체크리스트로 되어 있습니다. 필요할 때만 "화면 보기"를 눌러 오렌지 캡처를 볼 수 있습니다.
- **문제:** 숫자 입력, 객관식, 짝 맞추기, 기록형, 서술형이 있습니다. 대부분 바로 채점되고, 힌트를 볼 수 있습니다. 3번 틀리면 "정답 보기"가 나타납니다.
- **제출:** 마지막 미션 **08 정리 · 제출**에서 **PDF로 저장**을 누르면, 학번·이름과 모든 미션의 답·결과가 담긴 결과지가 PDF로 만들어집니다. 이 PDF를 선생님이 안내한 곳에 제출합니다.

## 미션 구성

| 번호 | 미션 | 오렌지 위젯 | 주요 내용 |
|---|---|---|---|
| 00 | 지진 데이터 구하기 | (기상청 기상자료개방포털) | 데이터 수집, 열(속성)의 뜻: 진원·진앙·깊이 |
| 01 | 데이터 불러오기 | 파일 불러오기 (File) | Geo 애드온 미리 설치, 행·속성 개수, 결측치, meta |
| 02 | 기초 통계 확인 | 데이터 테이블, 열별 통계량 | 평균·최빈값·중앙값·분산, 평균과 중앙값의 차이 |
| 03 | 조건으로 행 고르기 | 행 필터링 (Select Rows) | 초과(is greater than)와 이상(is at least) |
| 04 | 히스토그램 | 데이터 분포 (Distributions) | 구간별 빈도, Bin width |
| 05 | 박스 플롯 | 박스플롯 (Box Plot) | 사분위수, 표준편차, IQR |
| 06 | 산점도 | 산점도 (Scatter Plot) | 두 속성의 관계, 색으로 세 번째 속성 보기 |
| 07 | 지도로 보기 | Geo Map | 위도·경도로 지도에 표시, 큰 지진의 위치 |
| 08 | 정리 · 제출 | | 알게 된 점, 지진 대비 아이디어, PDF로 저장 |

위젯 이름은 오렌지3 한글 패치 기준이며, 처음 나올 때 영어 이름을 함께 적었습니다.

## PDF로 저장하기

1. **08 정리 · 제출**에서 **PDF로 저장**을 누릅니다. 맨 위에 학번과 이름을 적어야 동작합니다.
2. 인쇄 창이 열리면 **대상**(프린터)을 **PDF로 저장**으로 바꾸고 **저장**을 누릅니다.
3. 파일 이름은 `오렌지3지진데이터_학번_이름.pdf`로 자동으로 정해집니다.

결과지에는 00~08번 미션별로 문제, 내 답, 결과(정답·오답·기록·안 함)가 표로 들어갑니다.

## 수업 전 준비

1. 컴퓨터실 PC에 오렌지3를 설치하고, 학생들이 **관리자 권한으로 실행**할 수 있는지 확인합니다. Geo 애드온 설치에 관리자 권한이 필요합니다.
2. 데이터 파일 `EQK.csv`를 학생들에게 미리 나눠 줍니다. 기상청 사이트에서 1개월 넘는 데이터를 받으려면 로그인이 필요하기 때문입니다.
3. 한 대로 미리 끝까지 풀어 보고 PDF가 잘 저장되는지 확인합니다.
4. 학생 답은 웹앱 창(탭)에만 임시로 저장되고, **창을 닫으면 자동으로 지워집니다.** 그래서 한 컴퓨터를 여러 학생이 써도 앞 학생의 답이 보이지 않습니다. 새로고침은 괜찮지만 창을 닫으면 처음부터 다시 풀어야 합니다. 답을 적은 뒤 창을 닫으려 하면 확인 창이 한 번 뜹니다. **창을 닫기 전에 꼭 PDF로 저장**하게 해 주세요.

## 고치는 방법

- **문제나 설명 수정:** `index.html`에서 `const MISSIONS`를 찾으면 미션별 따라 하기 단계(`steps`)와 문제(`qs`)가 있습니다.
- **깃허브에 반영:** 저장소에서 **Add file → Upload files**로 새 `index.html`을 올리고 **Commit changes**를 누릅니다. 1~2분 뒤 반영됩니다.

## 알아 둘 점

- 바로 채점하려고 정답이 `index.html` 안에 들어 있습니다. 공개 저장소라서 코드를 열어 보면 정답을 볼 수 있습니다.
- 학생 로그인이 없어서, 학생이 입력한 학번과 이름이 그대로 PDF에 들어갑니다.
